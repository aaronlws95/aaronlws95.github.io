## Aaron's Personal Website

### Setup

Running the [scripts](scripts/) requires:

- python=3.11
- `pip install -r requirements.txt`


#### wkhtmltopdf

```bash
wget https://github.com/wkhtmltopdf/wkhtmltopdf/releases/download/0.12.4/wkhtmltox-0.12.4_linux-generic-amd64.tar.xz
sudo tar xvf wkhtmltox-0.12.4_linux-generic-amd64.tar.xz
sudo mv wkhtmltox/bin/wkhtmlto* /usr/bin/
```

Once per machine, install the Roboto font variant used for the CV PDF:

```bash
sudo apt install fonts-roboto
python3 scripts/install_roboto_cv.py
```

### Scripts

Run the scripts from the root directory.

### Build

`python scripts/build.py` builds the site into `dist/` (not committed; CI builds and deploys it).
Shared head, nav and footer live in [templates/](templates/); page content in [templates/pages/](templates/pages/).
Preview locally with `python -m http.server -d dist`.

The build also renders the CV PDF from [cv/cv.html](cv/cv.html) with wkhtmltopdf, so CI regenerates it on every deploy.
To build without wkhtmltopdf installed, use `python scripts/build.py --skip-pdf`.

### Projects

To add a new project

1. Create a new folder in [projects](projects/)
2. Add a `project_info.yaml` (following existing template)
3. `python scripts/build.py`

### CSS

`dist/css/style.css` is generated by `build.py` by concatenating the other css files.
